## Android TV'ye kurulum

1. Play Store'dan **Downloader** (AFTVnews) uygulamasını kur ve aç.
2. Adres alanına `tinyurl.com/29qjdscw` yaz → **Go**. İndirme bitince **Install** çıkacak.
3. "Bilinmeyen kaynak" uyarısı gelirse: **Ayarlar → Uygulamalar → Downloader → Bu kaynaktan yüklemeye izin ver**, sonra tekrar dene.

> Not: Paket sadece 64-bit ARM içerir. Eski/32-bit bir Android TV'de kurulum "uyumlu değil" diyebilir.
